Testbench

This directory contains the self-checking testbench used to verify the AMBA APB Slave.



Features:


• Self-checking verification

• Behavioral reference (Golden) model

• Reusable APB read/write tasks

• Automatic pass/fail reporting

• Register and RAM verification

• Invalid address testing

• PREADY and PSLVERR verification

• Waveform generation for simulation analysis
